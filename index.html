Complete Setup Guide (60 Seconds)

Set up ProjectBrain on any repository so your AI coding agent stops running blind grep loops and full-file reads.

Step 1 Install from PyPI

Install the official projectbrain-mcp package globally (exposes both the projectbrain CLI and projectbrain-mcp server):

pip install projectbrain-mcp

# Verify CLI and MCP server binaries are on PATH:
projectbrain --help
projectbrain-mcp --help

Step 2 Initialize Your Repository in One Command

Run projectbrain init inside your repository (or pass --path):

projectbrain --path /path/to/your/repo init

What init automatically sets up:
1. Indexes your codebase into .projectbrain.json and .projectbrain_graph.json in ~90ms.
2. Updates .gitignore so index caches never pollute Git.
3. Creates .mcp.json for Claude Code, Cursor, Windsurf, and Google Antigravity.
4. Creates .agents/rules/projectbrain.md and AGENTS.md so agents automatically compile a single-read dossier first.

Step 3 MCP Server Configuration (or Zero-Install via uvx)

If your IDE uses a global MCP config file (.cursor/mcp.json, claude_desktop_config.json, or Antigravity mcp_config.json), add:

{
  "mcpServers": {
    "projectbrain": {
      "command": "projectbrain-mcp",
      "args": ["/path/to/your/repo"]
    }
  }
}

// Or run with zero manual install via uvx:
{
  "mcpServers": {
    "projectbrain": {
      "command": "uvx",
      "args": ["projectbrain-mcp", "/path/to/your/repo"]
    }
  }
}

Step 4 Parent / Monorepo Workspace Rule (Important for Nested Repos)

If you open a parent directory in your IDE (e.g., /workspace containing /workspace/my-app), place an AGENTS.md (or .agents/rules/projectbrain.md) at the workspace root and pass --path "<subfolder>" so the agent always triggers ProjectBrain from the parent folder:

# ProjectBrain Mandatory Codebase Investigation & Editing Rules

1. Compile a Single-Read Engineering Dossier:
   projectbrain --path "<subfolder>" dossier "<question_or_bug>"
   Immediately read <subfolder>/.projectbrain_dossier.md in one read_file call (StartLine=1, EndLine=800).

2. Surgical Symbol Slicing:
   projectbrain --path "<subfolder>" slice --summary <file:symbol_or_start-end>

3. Surgical Anchor Patching:
   projectbrain --path "<subfolder>" patch --spec "<Anchor Patch DSL>" --apply

Step 5 Keep Git Clean (.gitignore)

Add these patterns to .gitignore to keep all local ProjectBrain caches, dossiers, diffs, and agent rule files untracked:

Daily CLI Workflow & Live ROI Dashboard

Use ProjectBrain directly from your terminal or let your AI coding agent invoke it automatically via CLI or MCP.

1. Compile a Single-Read Engineering Dossier (dossier)
# Compiles module constants, folded AST slices, 1-3 hop call chains,
# and a Closed-World Exhaustive Repo Scan into .projectbrain_dossier.md (<800 lines)
$ projectbrain --path /path/to/repo dossier "what role does questionnaire have in onboarding"
2. Surgically Slice Specific Symbols (slice)
# Extract exact AST lines for 1-2 symbols without reading full files
$ projectbrain --path /path/to/repo slice --summary src/App.tsx:ProtectedRoute src/data/questionnaireData.ts:calculatePersona
3. Apply Surgical Anchor Patches (patch)
# Cuts edit output tokens by 65-80% with instant Tree-sitter syntax validation
$ projectbrain --path /path/to/repo patch --apply --spec "@file src/App.tsx
@sub L84 \`!profileCompleted\` -> \`isHydrated && !profileCompleted\`"

Core Capabilities

Input Saver

Single-Read Engineering Dossier (brain_dossier)

Compiles module globals, smart-folded AST function slices, 1–3 hop bidirectional call chains, and a Closed-World Exhaustive Repo Scan into a single <800-line .projectbrain_dossier.md.

Output Saver

Surgical Anchor Patching (brain_patch)

Replaces verbose before/after blocks in edit_file with compact anchor specs (@file, @sub, @replace, @insert_after, @delete) validated by Tree-sitter in <5ms.

Telemetry

Live ROI & Savings Ledger (brain_stats)

Automatically records every dossier, slice, and patch operation to .projectbrain_ledger.json, reporting input/output tokens saved and tool calls avoided.

Anti-Hallucination

3-Valued Verification (brain_check)

Verifies structural claims (SUPPORTED, REFUTED, UNKNOWN) and edit plans against the parsed code graph with zero false refutations.

Memory

AST-Anchored Repo Memory (brain_remember)

Pins architectural invariants to specific symbols in .projectbrain_memory.json and automatically flags [STALE WARNING] when a function's AST hash changes.

Graph

Cross-Framework Route & Import Resolution

Resolves Python relative/symbol imports, TypeScript path aliases (@/, ~/), and FastAPI, Flask, Django, Express, and Next.js routes out of the box.
